KeePassXC — Material

A fork of KeePassXC whose interface is rebuilt from the ground up. Not a theme layered over the stock widgets — the old styling is gone.

View on GitHub Read the wiki

What changed

The cryptography, KDBX handling, browser and SSH integrations, and keepassxc-cli are upstream code and untouched. Presentation is the whole scope.

One design system

Every colour, radius, duration and row height resolves through a token engine. No widget hard-codes a value.

Live appearance

Theme, seed colour, density and font change the running application. No restart.

Nothing left behind

BaseStyle (4 860 lines), LightStyle, DarkStyle, four .qss files and the scattered per-widget stylesheets were deleted.

Seeds

The seed supplies the primary and container roles. Surfaces, outlines and status colours come from the light or dark family.

Passkeys

Saving a passkey is the part that must not break, so it is the part with real tests.

The credential id, private key and user handle are written protected. An unprotected private key sits in the KDBX in plaintext and defeats the point of storing it there.

Build it

git clone --depth 1 https://github.com/microsoft/vcpkg.git "$HOME/vcpkg"
"$HOME/vcpkg/bootstrap-vcpkg.sh" -disableMetrics

cmake -B build -S . -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_TOOLCHAIN_FILE="$HOME/vcpkg/scripts/buildsystems/vcpkg.cmake"
cmake --build build --parallel

Full instructions, including the vcpkg baseline gotcha, are in the Building page.
