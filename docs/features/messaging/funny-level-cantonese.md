# Funny level, Cantonese

Feature id: `funny-level-cantonese` · Category: Messages, language and voice

## Behaviour

The Cantonese counterpart of the English slider: an independent 1 to 5 level for Hong Kong Cantonese copy that stays respectful at every level and keeps the same facts as the English line.

## Configuration

`GUI/FunnyLevelCantonese`, persisted; Appearance › Voice.

## Failure modes

Same as the English slider: shipped default 3 instead of 5.

## Security considerations

None beyond the fact enforcement.

## Verification

`testmaterialvoice`.
