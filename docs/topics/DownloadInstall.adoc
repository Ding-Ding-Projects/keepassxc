== Downloading KeePassXC

This fork supports 64-bit Microsoft Windows 10 and Windows 11. Each successful release publishes an unsigned Squirrel.Windows `Setup.exe`, its `RELEASES` feed, and a full `.nupkg` update package.

Download the assets from the fork's verified https://github.com/Ding-Ding-Projects/keepassxc/releases[GitHub Releases] page. Do not download installers from unrelated third-party sites.

=== Microsoft Windows

To install KeePassXC, download `Setup.exe` from the intended release and open it. Squirrel.Windows installs the application per user and creates its application shortcut without requiring an administrator installation.

IMPORTANT: Code signing is permanently disabled for this project. Windows may display an *Unknown Publisher* or SmartScreen warning. The application and installer do not claim publisher-signature verification. Compare the downloaded file's SHA-256 with the release's `artifact-receipt.json` and confirm that the receipt names the intended source commit and version before continuing.

Updates use the same Squirrel.Windows package identity. The application downloads and validates the release feed and package hashes in the background, then waits for the user to choose *Restart to install update*. It never restarts automatically, and deferring an update leaves the current version running.

The Squirrel installation directory is versioned and application-owned. Store password databases in a user-selected data location, not inside the installation directory. Updating or uninstalling the application does not authorize deletion of user databases.

During install and update lifecycle events, the application refreshes its Squirrel shortcut and the browser native-messaging, `.kdbx` Open With, and `keepassxc:` URI records that this installation owns. Lifecycle flags are accepted only in Squirrel's first argument position with the expected version argument. Uninstall removes only records carrying this installation's ownership marker; it does not remove password databases, application data, foreign handlers, or another application's registration.

Portable ZIP, MSI, WiX, NSIS, Linux, and macOS installation routes are not supported by this fork.
